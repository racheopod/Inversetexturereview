# Data, code, and figures for *The inverse texture effect in drylands: mechanisms, misconceptions, and ecological relevance*

#### Renne, Rachel R. & Lauenroth, William K.

#### 2026-09-23

#### Repository created by Rachel R. Renne

[![DOI]()

---

This repository includes table of sources used in the literature review and code for creating all figures.

Tables of sources used in the literature review, including raw exports from Zotero are found in
`01_Data`.

Scripts (`02_Code`) are numbered in order of the analysis:

- `01_Combining_ZoteroExports_v2.R`
- `02_CharacteristicLength_and_EvaporationEfficiency_ITE.R`
- `03_WaterContent_and_PlantAvailableWater.R`
- `04_Summarize_ITE_Literature.R`
- `05_CitationNetwork.R`

Figures generated for the publication and supplemental information are
found in `03_Figures`.
